Introduction:
This portfolio shows the practical Cybersecurity skills I have developed through my university studies. I used TryHackMe to complete a beginner level offensive security exercise in a safe and legal training environment. the activity helped me to understand Cybersecurity professionals use websites to identify weaknesses and why it is important to protect sensitive pages. 
Project Objectives
The main objectives of this project were to understand the basic principles of offensive security, to learn how to use a cybersecurity scanning tool, identify hidden webpages in a simulated banking application, to develop practical skills and to show how weaknesses in security can affect a website.
TryHackMe is an online website which provides practical cybersecurity training.
DIRB is a directory scanning tool which is used to find hidden webpages.
Linux Terminal is used to execute the scanning command.
FakeBank is a banking application which is used to test authorised security.
Accessing the Training Environment: I registered on the TryHackMe and opened the Offensive Security into room. I  learnt about offensive security and how ethical hackers identify  weaknesses in system. 
exploring the FakeBank: I accesses the FakeBank application through virtual desktop. The banking website displayed account information and negative balance.
Scanning the hidden pages: I opened the Linux terminal and entered http://fakebank.thm which identified two paths which are; /bank-transfer, /images. This shows how directory scanning can reveal webpages that are not directly linked from the main page of the websites. 
Testing the security weakness: I accessed the hidden bank transfer page in authorised TryHackMe simulation. i made a deposite of $2000 into the provided account. the application confirmed that the deposit has been successful.
i completed the four Tasks in Offensive Security Intro room and recieved the confirmation of completion.
